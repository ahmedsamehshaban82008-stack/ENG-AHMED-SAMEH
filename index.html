02 / PROGRAMMING EXPLAINED

يعني إيه برمجة؟ 🤔What Is Programming? 🤔

البرمجة هي إنك تشرح للكمبيوتر يعمل إيه، وإمتى يعمله، وإزاي ينفذه — بتعليمات واضحة ومنظمة.Programming means telling a computer what to do, when to do it, and how to do it through clear, structured instructions.

من الفكرة للكود… ومن الكود لحل حقيقيFrom an Idea to Code, From Code to a Real Solution

تخيل إنك عايز تعمل برنامج يحسب مجموع درجات طالب. بدل ما تحسبها كل مرة بإيدك، تقدر تكتب تعليمات تخلي الكمبيوتر يستقبل الدرجات، يجمعها، وبعدها يعرض النتيجة.

البرمجة بتعتمد على التفكير المنطقي وتقسيم المشكلة لخطوات صغيرة، واختيار لغة يفهمها الكمبيوتر من خلال المترجم أو بيئة التشغيل.

ومع التدريب، تقدر تستخدم نفس الفكرة لبناء مواقع، وتطبيقات موبايل، وألعاب، وأنظمة شركات، وأدوات ذكاء اصطناعي.

Imagine creating a program that calculates a student's total score. Instead of doing it manually every time, you can write instructions that receive scores, add them, and display the result.

Programming relies on logical thinking, breaking problems into small steps, and using a language executed through a runtime or compiler.

With practice, the same ideas can power websites, mobile apps, games, business systems, and AI tools.

hello_world.py
name = "Ahmed Sameh"
scores = [85, 92, 78]

total = sum(scores)
average = total / len(scores)

print(f"Hello, {name}!")
print(f"Total: {total}")
print(f"Average: {average:.1f}")

# Output:
Hello, Ahmed Sameh!
Total: 255
Average: 85.0
① تحليل المشكلةUnderstand the Problem

حدد المطلوب، والبيانات اللي هتدخل، والنتيجة اللي عايز توصل لها.Define the task, the input data, and the result you want.

② كتابة الخوارزميةDesign an Algorithm

رتّب خطوات الحل بشكل منطقي قبل كتابة الكود.Arrange the solution steps logically before coding.

③ التجربة والتحسينTest & Improve

اختبر البرنامج، اكتشف الأخطاء، وحسّن الأداء والوضوح.Test the program, find bugs, and improve clarity and performance.
